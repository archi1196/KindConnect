# KindConnect — Public deployment package

Student project for the societal internship under Hanuman Kind Foundation, Surat.

## Password gate
- Local default password: `USER@12340`
- For public deployment, set `SITE_PASSWORD` in the host's environment settings to `USER@12340` (or another private password).
- Set `SECRET_KEY` to a long random value. Render's blueprint can generate this value.
- The login gate protects dashboard routes and Excel export. Do not publish this repository publicly with a real secret or real volunteer records.

## Deploy to Render (free demo)
1. Create a GitHub account if needed, then create a new repository and upload all files/folders in this project.
2. In Render, choose **New + → Blueprint** and connect that repository, or create a Web Service from the repo.
3. The included `render.yaml` configures `pip install -r requirements.txt` and `gunicorn app:app`.
4. In Render environment settings, set `SITE_PASSWORD` to `USER@12340`; set `SECRET_KEY` to a strong random value if not generated by the blueprint.
5. Deploy and use the public `*.onrender.com` URL on phones and computers.

## Important hosting limitations
- Render's free web services can spin down after inactivity, so the first visit may take a little while. Free hosting does not guarantee uninterrupted 24/7 availability.
- This version uses SQLite and writes `KindConnect_Live_Records.xlsx` beside the app. On ephemeral free hosting, local database/Excel files may be lost on restart or redeploy. Do not collect real volunteer details publicly until a persistent disk or managed online database and backups have been configured.
- Shared password means everyone who knows it can enter. It is a basic shared gate, not individual accounts; do not expose personal volunteer records on a public dashboard.
- The Excel export route is password-protected. The `/health` endpoint is intentionally public for host health checks.

## Run locally
`pip install -r requirements.txt` then `python app.py`, then visit `http://127.0.0.1:5000`.
